Validation options
DKIM selectorsComma- or space-separated list of selectors to probe. Filled in with the domain's configured list when it has one, otherwise the server's defaults; edit it to probe something else this time.
BIMI selectorsComma-separated; each is checked as <selector>._bimi.<domain> and reported separately. Filled in like the DKIM list — the domain's configured selectors, otherwise the server's defaults (normally just default, the one receivers use when a message names none).
